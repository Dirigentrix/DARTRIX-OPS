# DARTRIX-OPS

Operational demo scaffold for AI, automation, and delivery workflows.

This project provides a clean base for local development, prototype validation, and deployment testing. It is meant to support practical demos rather than experimental presentation language.

## Use cases

- CI/CD and deployment patterns
- AI Studio and Gemini-based prototypes
- Workflow automation
- Rapid demo delivery

## Local run

1. Install dependencies: `npm install`
2. Add `GEMINI_API_KEY` to `.env.local`
3. Run: `npm run dev`
